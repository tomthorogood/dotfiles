# Non-brew apps checklist

Apps in `/Applications` that aren't available via Homebrew cask (or whose
cask is broken/unreliable). Reinstall these manually on a new Mac.

- [ ] **Logic Pro** — Mac App Store
- [ ] **Strongbox** — Mac App Store (or https://strongboxsafe.com)
- [ ] **MuseScore 4** — https://musescore.org/en/download (cask is broken as of writing)
- [ ] **Muse Hub** — https://www.presonus.com/products/muse-hub (soundfont/plugin manager, pairs with MuseScore)
- [ ] **Logi Tune** — https://www.logitech.com/en-us/software/logi-tune.html
- [ ] **NUX Device Updater** — vendor site (NUX gear firmware updater)
- [ ] **Wondershare DemoCreator** — https://democreator.wondershare.com
- [ ] **Azure VPN Client** — https://aka.ms/azvpnclient
- [ ] **Company Portal / Self Service / Microsoft Defender / Global Secure Access** — installed automatically via Intune device enrollment; just enroll the new Mac and these show up

## No action needed

- **Google Docs/Sheets/Slides.app** — these are just Chrome-installed web
  app shortcuts. They regenerate automatically the first time you install
  them from within Chrome; no separate download needed.
- **1Password 7.zip** — leftover installer artifact, safe to ignore/delete.

## Handled elsewhere

- Raycast snippets/settings — synced via Raycast Pro cloud sync, just sign in.
